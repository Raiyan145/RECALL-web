# RecallPro Web — ARVION

This is a lightweight browser preview of the RecallPro reminder app design.

It mirrors the current app concept:
- Normal and Emergency reminders
- Reminder creation UI
- Dashboard and upcoming reminders
- ARVION branding

## Run
Simply open `index.html` in Chrome/Edge/Firefox.

No Flutter, Android Studio, Node.js or installation is required.

## Note
This browser version is a UI/prototype preview. Native Android notification sound, vibration, Google Sign-In, and background scheduling require the Android/Flutter version.
